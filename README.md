Explanation
The function loops through each character in the input string s.
For every character, it multiplies it by 3 (char * 3) to repeat it.
These repeated characters are added into result.
Finally, the function returns the full string.
Example:
Input: "Hi-There"
"H" → "HHH"
"i" → "iii"
"-" → "---"
... and so on → "HHHiii---TTThhheeerrreee"
